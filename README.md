# Concept Graph Homebrew tap

On your Mac, add the tap and trust the Concept Graph formula once.

```sh
brew tap briansynthetaic/tap
brew trust --formula briansynthetaic/tap/concept-graph
```

Install or update the viewer and bundled skill with the same command.

```sh
brew install concept-graph
```

After installation, run `concept-graph link codex` for Codex or `concept-graph link claude` for Claude Code. If you use both, run both commands. In a conversation you want to map, ask your agent:

> map this conversation to a concept-graph.

[Full Mac setup instructions](https://github.com/briansynthetaic/agent-concept-graph#open-your-first-graph-on-your-mac)
